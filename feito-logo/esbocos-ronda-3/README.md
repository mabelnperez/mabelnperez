# Feito — esboços de logo, ronda 3 (editorial)

A direção escolhida foi a editorial, menos literal: só tipografia, sem cadernos nem vistos desenhados. A ideia de cada versão está num detalhe.

| Versão | Ideia | Ficheiros |
|---|---|---|
| 1 — Ponto final (recomendada) | "Feito." — a palavra já quer dizer concluído, e o ponto rosa fecha a tarefa. Inclui o ícone "F." e um selo redondo para embalagens. | `1-ponto-final-*.svg` |
| 2 — Itálico | O itálico como "mão" dentro da tipografia, com a estrela da marca atual no i. | `2-italico-*.svg` |
| 3 — Assinatura | Maiúsculas condensadas (estrutura) com "para quem faz" em cursiva (a mão). | `3-assinatura-*.svg` |

Paleta igual à da ronda 2: Vinho `#6B2138`, Linho `#F3E7D7`, Blush `#E8C4CB`, Rosa `#C0697A`, Tinta `#2B2522`.

Tipos usados só para esboçar, todos com licença livre (Google Fonts): Gloock, Bodoni Moda, Instrument Serif, Pinyon Script e Courier Prime. As letras já estão em contornos; para a versão final, o ideal é ajustar ou redesenhar o nome para ser exclusivo.
