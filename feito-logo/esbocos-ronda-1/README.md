# Feito — esboços de logo, ronda 1

Esboços para discussão, não são a versão final. Usam a paleta atual (azul ardósia `#526580`, lavanda `#B7A9D6`, marfim `#F7F4EF`, névoa `#D5C8DA`) e um wordmark `feito` em minúsculas, desenhado à mão com traços geométricos simples (sem fonte instalada).

| Direção | Ideia | Ficheiros |
|---|---|---|
| A — Meada (recomendada) | Um fio solto dá uma volta e resolve-se num visto: da ponta solta ao "feito". | `a-meada-*.svg` |
| B — Gavetas | Um F feito de módulos numa grelha 3×3; a faísca lavanda ocupa o lugar livre. | `b-gavetas-*.svg` |
| C — Etiqueta | Uma etiqueta de preço com o F do monograma atual e um fio solto. | `c-etiqueta-*.svg` |

Cada direção tem: `-simbolo`, `-assinatura` (horizontal), `-assinatura-negativa` (marfim, para fundos escuros) e `-icone-app`. `feito-wordmark.svg` é o wordmark sozinho.

Os traços estão em `stroke`: no Illustrator, usar *Objeto › Expandir* antes de finalizar.
